Privacy policy

ClamTotal is a self-hosted file-analysis service. When you upload a file, it is sent to the ClamTotal server you are using, where it is scanned and handled as described below. Nothing is sent anywhere else: no external APIs, no third-party services, no telemetry.

What we collect

  • Files you upload — stored on the server (by SHA-256). {{ ttl_sentence }}
  • Scan metadata — file name(s), hashes, verdicts, extracted indicators (URLs, domains, IPs, emails, registry keys) and static-analysis results, stored in the local SQLite database on the server. {{ scans_sentence }} When a scan result is deleted, the stored sample file is deleted with it.
